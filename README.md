# Amsterdam Imaging Hub

Website for the Amsterdam Imaging Hub, built with [Quarto](https://quarto.org).

Originally based on the [Quarto Academic Website Template](https://github.com/drganghe/quarto-academic-website-template) (MIT).

## Editing

- News and events: add a folder under `posts/` with an `index.qmd`, or an external link in `posts/post-links.yml`.
- People: `people/board.yml`, `people/ambassadors.yml`.
- Facilities: `facilities.yml`. Projects: `projects.yml` (page is hidden from the navbar while empty).
- Preview with `quarto preview`; publish with `quarto render` (output goes to `docs/`).
